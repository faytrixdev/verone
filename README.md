# CRM Immobilier & Prospection IA

Système CRM sur mesure pour une agence immobilière au Burkina Faso.

L'application combine deux besoins principaux :

1. **Gestion immobilière** : gérer les biens, les demandes, les prospects et les opportunités.
2. **Prospection assistée par IA** : rechercher de nouveaux prospects, récupérer les informations disponibles, les qualifier et les classer automatiquement.

## Objectif

Créer un outil simple permettant à l'agence de :

* gérer son portefeuille de biens ;
* centraliser ses prospects et clients ;
* suivre les demandes immobilières ;
* suivre les opportunités commerciales ;
* éviter les doublons de prospects ;
* rechercher régulièrement de nouveaux prospects ;
* qualifier automatiquement les prospects avec l'IA ;
* classer les prospects selon leur niveau : VIP, cadre moyen ou employé ;
* suivre les actions effectuées avec chaque prospect.

## Marché cible

Le système est destiné à une agence opérant principalement au Burkina Faso.

Zones prioritaires :

* Ouagadougou
* Bobo-Dioulasso
* Koudougou
* Ouahigouya
* Banfora
* Pouytenga
* Ziniaré
* autres grandes villes du Burkina Faso

## Stack prévue

* Next.js
* TypeScript
* Tailwind CSS
* Supabase
* Serper
* Exa
* API LLM pour la qualification
* n8n pour les automatisations futures

## Principe important

Les captures d'écran et CRM fournis par le client servent uniquement de référence fonctionnelle.

L'application ne doit pas copier leur design ou leur structure exacte.

Elle doit être conçue autour des besoins spécifiques définis pour ce projet.

## Développement

La première étape est une démonstration fonctionnelle.

La démo doit permettre de vérifier :

* la recherche de prospects ;
* la qualité des données trouvées ;
* la qualification par IA ;
* la classification ;
* l'enregistrement dans le CRM.

Les fonctionnalités avancées seront ajoutées progressivement après validation de la démo.
