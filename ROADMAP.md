# Roadmap

## Phase 0 — Prototype de faisabilité

Objectif : vérifier que la recherche de prospects fonctionne réellement au Burkina Faso.

### À faire

* connecter Serper ;
* connecter Exa ;
* tester plusieurs recherches ;
* récupérer des résultats ;
* extraire les informations ;
* tester la qualification IA ;
* tester la classification VIP / cadre moyen / employé ;
* tester la détection de doublons.

### Critère de validation

Obtenir un petit ensemble de prospects suffisamment pertinents pour démontrer le fonctionnement du système.

# Phase 4 — Matching immobilier

Permettre au système de connecter automatiquement :

**Demandes ↔ Biens**

Exemple :

Un client recherche une villa à Ouagadougou entre 30M et 40M FCFA.

Le système identifie les biens correspondants.

## Priorité

La priorité absolue est de démontrer que :

**le système peut trouver des prospects pertinents → les qualifier → les classer → les intégrer au CRM.**

Le CRM immobilier vient ensuite compléter cette fonctionnalité.

Ne pas développer les fonctionnalités avancées avant d'avoir validé cette boucle principale.
